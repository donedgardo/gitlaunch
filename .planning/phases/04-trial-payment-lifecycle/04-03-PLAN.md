<objective>
Implement payment failure grace periods with UI warnings and integrate with existing read-only enforcement.

Purpose: When a user's payment fails, they should not be immediately locked out. Industry standard is a 7-day grace period. During grace, the user sees a warning but retains full access. After grace expires, existing read-only enforcement kicks in (restrict mutations). The dashboard and billing settings page show appropriate warnings.

Output: Grace period logic in PlanEnforcementService, UI warnings on dashboard and billing settings, integrated with existing paymentFailedAt webhook handling.
</objective>

  <behavior>
    **PlanEnforcementService grace period methods:**
    - isInGracePeriod(account): returns true if paymentFailedAt is set AND within 7 days, false otherwise
    - getGracePeriodDaysRemaining(account): returns number of days remaining in grace period (0 if not in grace)
    - GRACE_PERIOD_DAYS = 7 as exported constant

    **getAccountState extension (from 04-02):**
    - Add gracePeriodDaysRemaining to return type
    - Add paymentFailed: boolean to return type
    - isReadOnly should also be true when: payment failed AND grace period expired (past 7 days)
    - isReadOnly should be false when: payment failed BUT within grace period (still has access)

    Cases:
    - No paymentFailedAt -> isInGracePeriod: false, gracePeriodDaysRemaining: 0
    - paymentFailedAt 3 days ago -> isInGracePeriod: true, gracePeriodDaysRemaining: 4
    - paymentFailedAt 7 days ago -> isInGracePeriod: false, gracePeriodDaysRemaining: 0
    - paymentFailedAt 10 days ago -> isInGracePeriod: false, isReadOnly: true (if subscribed user)
    - Payment failed 2 days ago, Pro plan, 8/10 repos -> isReadOnly: false (in grace period)
    - Payment failed 8 days ago, Pro plan, 8/10 repos -> isReadOnly: true (grace expired, still has subscription but restricted)

    **Dashboard UI:**
    - Show payment failure warning when paymentFailed is true and in grace period:
      "Payment failed. Please update your payment method within X days to avoid service interruption."
      Link to /settings/billing
    - Red/danger style banner, more urgent than trial countdown
    - Banner priority: payment failure > trial countdown > read-only (show most urgent)

    **Billing settings page:**
    - Show payment failure warning when account.paymentFailedAt is set:
      "Your last payment failed. Please update your payment method to continue service."
      Show "Update Payment Method" button linking to Stripe Customer Portal
    - Show grace period countdown: "X days remaining before access is restricted"

  <behavior>
    **TrialService.checkAndHandleTrialExpiry(accountId):**
    - If account has no trialEndsAt (null) -> returns { expired: false }
    - If account has trialEndsAt in the future -> returns { expired: false }
    - If account has trialEndsAt in the past AND no stripeSubscriptionId -> calls accountRepo.downgradeToFree(accountId), sets trialEndsAt to null, returns { expired: true, downgraded: true }
    - If account has trialEndsAt in the past BUT has stripeSubscriptionId -> clears trialEndsAt (user subscribed during trial), returns { expired: false }

    Cases:
    - No trial -> { expired: false }
    - Active trial (5 days left) -> { expired: false }
    - Expired trial, no subscription -> { expired: true, downgraded: true }
    - Expired trial, has subscription -> { expired: false } (clears stale trialEndsAt)

    **PlanEnforcementService.getAccountState(accountId):**
    - Returns { plan, isReadOnly, usage, trialDaysRemaining }
    - isReadOnly is TRUE when: usage.repositories.current > usage.repositories.limit OR usage.services.current > usage.services.limit
    - isReadOnly is FALSE when within limits
    - trialDaysRemaining: computed from account.trialEndsAt (0 if null or expired)

    Cases:
    - Free account with 2/3 repos -> { isReadOnly: false }
    - Free account with 5/3 repos (downgraded from Pro) -> { isReadOnly: true }
    - Pro account with 8/10 repos -> { isReadOnly: false }
    - Account on trial with 7 days left -> { trialDaysRemaining: 7 }

    **AccountRepository.upgradeToPlan extension:**
    - Must also set trialEndsAt: null when upgrading (clears trial state on subscription)

    **Onboarding /onboarding/select-plan wiring:**
    - When user selects Pro or Team: call trialService.startTrial(accountId, githubId, plan)
    - Need to look up user's githubId from session.userId via userRepository
    - If trial already used: still select the plan (they chose it) but don't start trial
    - Free plan selection: call accountRepo.selectPlan directly (no trial)

    **Dashboard wiring:**
    - On dashboard load (before rendering): call trialService.checkAndHandleTrialExpiry(accountId)
    - Call planEnforcementService.getAccountState(accountId) to get trial/read-only state
    - Pass trialDaysRemaining and isReadOnly to template
    - Dashboard template shows trial countdown banner when trialDaysRemaining > 0

    **Trial countdown UI (dashboard.hbs):**
    - Show banner: "Trial: X days remaining. Subscribe to keep your plan." with link to /settings/billing
    - Only shown when trialDaysRemaining > 0
    - Yellow/warning style banner at top of dashboard
    - Read-only banner: "Your account exceeds Free plan limits. Resources are read-only. Upgrade to restore full access." shown when isReadOnly is true

  </behavior>

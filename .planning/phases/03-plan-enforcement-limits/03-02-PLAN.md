Output: All environment creation endpoints enforce plan limits, with behavior tests for the API route.

  <action>
    **1. Update SettingsRoutesDeps and registerSettingsRoutes** (`src/server/routes/services/settings.ts`):
    - Add `planEnforcementService: PlanEnforcementService` to `SettingsRoutesDeps` type
    - Import `PlanEnforcementService` from billing service
    - In the `POST /services/:serviceId/environments` handler, BEFORE calling `environmentService.addEnvironment()`, add:
      ```typescript
      // Check environment limit
      const canAdd = await planEnforcementService.canAddEnvironment(accountId, service._id);
      if (!canAdd.allowed) {
        const environments = [...service.environments].sort((a, b) => a.order - b.order);
        return reply.view("partials/environmentList", {
          environments,
          canDelete: environments.length > 1,
          serviceId: service._id.toString(),
          error: canAdd.reason,
        });
      }
      ```
    - This follows the exact same pattern as the existing error handling in the catch block.

    **2. Update EnvironmentsRoutesDependencies and registerEnvironmentsRoutes** (`src/server/routes/api/environments.ts`):
    - Add `planEnforcementService: PlanEnforcementService` to `EnvironmentsRoutesDependencies` type
    - Add `accountRepo: AccountRepository` to dependencies (needed to resolve accountId from apiKey)
    - Import `PlanEnforcementService` and `AccountRepository`
    - In the `POST /api/v1/services/:serviceId/environments` handler, BEFORE calling `environmentService.addEnvironment()`, add:
      ```typescript
      // Check environment limit
      const canAdd = await planEnforcementService.canAddEnvironment(accountId, serviceId);
      if (!canAdd.allowed) {
        return reply.status(403).send({
          error: canAdd.reason,
          upgradeRequired: canAdd.upgradeRequired,
        });
      }
      ```
    - Use 403 status code (plan limit = forbidden, not 400 = bad request). This differentiates "your request is valid but your plan doesn't allow it" from "your request is malformed."

    **3. Wire planEnforcementService into route registrations** (`src/server/createAppServer.ts`):
    - Update `registerSettingsRoutes` call to include `planEnforcementService` in deps:
      ```typescript
      registerSettingsRoutes(server, {
        serviceRepository,
        repositoryRepository,
        environmentService,
        planEnforcementService,
      });
      ```
    - Update `registerEnvironmentsRoutes` call inside the API server register block to include `planEnforcementService`:
      ```typescript
      registerEnvironmentsRoutes(apiServer, {
        environmentService,
        planEnforcementService,
      });
      ```

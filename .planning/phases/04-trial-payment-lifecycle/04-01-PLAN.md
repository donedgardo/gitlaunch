  <behavior>
    **TrialRegistryRepository:**
    - claimTrial(githubId, accountId) inserts entry with unique githubId index
    - Returns true on success (trial claimed)
    - Returns false on duplicate key error (code 11000) — trial already used by this GitHub user
    - Throws on other errors
    - hasUsedTrial(githubId) checks if a GitHub user has already claimed a trial
    - ensureIndexes() creates unique index on githubId

    Cases:
    - First claim for githubId 12345 -> returns true, entry created
    - Second claim for githubId 12345 (same or different account) -> returns false
    - hasUsedTrial for githubId with existing entry -> returns true
    - hasUsedTrial for githubId with no entry -> returns false

    **Account schema extension:**
    - Add `trialEndsAt: Date | null` to Account type (null = not on trial)
    - CreateAccountInput unchanged (trials start later, not at account creation)
    - Account.create sets trialEndsAt to null by default

    **TrialService:**
    - startTrial(accountId, githubId, plan) orchestrates:
      1. Validates plan is Pro or Team (not Free — Free users don't get trials)
      2. Calls trialRegistryRepo.claimTrial(githubId, accountId)
      3. If claim succeeds: sets account.trialEndsAt to now + 14 days, calls accountRepo.selectPlan(id, plan)
      4. If claim fails (duplicate): returns { started: false, reason: "Trial already used" }
      5. Returns { started: true, trialEndsAt: Date } on success
    - getTrialStatus(accountId) returns current trial state:
      - { onTrial: false } if trialEndsAt is null
      - { onTrial: true, daysRemaining: N, trialEndsAt: Date } if trialEndsAt is in future
      - { onTrial: false, expired: true } if trialEndsAt is in past

    Cases:
    - startTrial with Free plan -> returns { started: false, reason: "Cannot start trial on Free plan" }
    - startTrial with Pro plan, first trial -> returns { started: true, trialEndsAt: <14 days from now> }
    - startTrial with Pro plan, trial already used -> returns { started: false, reason: "Trial already used" }
    - getTrialStatus with null trialEndsAt -> { onTrial: false }
    - getTrialStatus with future trialEndsAt -> { onTrial: true, daysRemaining: 13 }
    - getTrialStatus with past trialEndsAt -> { onTrial: false, expired: true }

  </behavior>

<objective>
Expand the Plan model from binary Free/Paid to three-tier Free/Pro/Team with distinct limits per tier, and make the entire billing service layer plan-aware so checkout sessions, webhook processing, and plan enforcement all use the correct plan.

Purpose: Foundation for all Phase 2 work. Without the correct Plan enum and plan-aware services, the plan picker and billing page cannot function correctly. A user selecting Team plan must get Team limits, not Pro limits.

Output: Updated Plan enum, per-tier limit constants, plan-aware MembershipService/StripeService/WebhookHandler, updated webhook route.
</objective>

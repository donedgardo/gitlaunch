<objective>
Create WebhookEventRepository that tracks processed Stripe webhook event IDs in MongoDB with a unique constraint to prevent duplicate processing.

Purpose: BILL-02 and BILL-03 require idempotent webhook processing. Stripe retries failed webhooks for up to 3 days, so the same event can arrive multiple times. Without idempotency, duplicate events corrupt subscription state (e.g., double upgrades, phantom downgrades). MongoDB's unique index on stripeEventId provides atomic, race-condition-safe deduplication.

Output: WebhookEventRepository with markAsProcessed method, ensureIndexes method, and comprehensive behavior tests.
</objective>

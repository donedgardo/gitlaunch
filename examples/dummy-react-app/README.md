# Dummy React App

A small Vite + React + TypeScript app. It exists to be deployed, not to be useful.

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
```

## Scripts

| Script            | What it does                      |
| ----------------- | --------------------------------- |
| `npm run dev`     | Vite dev server                   |
| `npm run build`   | Type-check, then build to `dist/` |
| `npm test`        | Run the vitest suite once         |
| `npm run preview` | Serve the built `dist/`           |

## Deploying

`npm run build` produces a static `dist/` directory. Ship it wherever static
files go.

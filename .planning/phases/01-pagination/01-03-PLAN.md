  <action>
    1. Register two new Handlebars helpers in registerHandlebarsHelpers.ts:
       - `add`: returns a + b (for computing next page: {{add pagination.currentPage 1}})
       - `subtract`: returns a - b (for computing prev page: {{subtract pagination.currentPage 1}})
       Both helpers take two number arguments and return their sum/difference.

    2. Create src/templates/partials/paginationControls.hbs with:
       - Wrapper div with flexbox layout (justify-between, items-center), border-t separator
       - Left: Previous button
         - If pagination.hasPrev: render as anchor tag with:
           - href="/dashboard/{{serviceName}}?page={{subtract pagination.currentPage 1}}" (progressive enhancement)
           - hx-get="/dashboard/{{serviceName}}?page={{subtract pagination.currentPage 1}}"
           - hx-target="#build-table"
           - hx-swap="outerHTML"
           - hx-push-url="true"
           - Tailwind classes: px-4 py-2 text-sm font-medium text-gray-700 bg-white border border-gray-300 rounded-md hover:bg-gray-50 dark:bg-gray-800 dark:text-gray-300 dark:border-gray-600 dark:hover:bg-gray-700
         - If NOT hasPrev: render as span with cursor-not-allowed, muted colors
       - Center: "Page {{pagination.currentPage}} of {{pagination.totalPages}}" text (text-sm text-gray-700 dark:text-gray-300)
       - Right: Next button (mirror of Previous but uses hasMore and add helper)
       - Only render the entire partial if pagination exists AND pagination.totalPages > 1 (don't show pagination for single page)

    3. Update src/templates/partials/buildTable.hbs:
       - After the closing </table> tag (but still inside the #build-table div), add:
         {{> paginationControls pagination=pagination serviceName=serviceName}}
       - This goes inside the `{{else if builds.length}}` block, after the table

    4. Register the new partial in dashboard test setup (index.test.ts beforeEach):
       - Add paginationControls: "/partials/paginationControls.hbs" to the partials object in the view plugin registration
       - This ensures existing tests don't break when buildTable tries to render the pagination partial

    5. Register the partial in registerPlugins.ts (or wherever Handlebars partials are registered for the app server):
       - Find where partials like buildTable, buildRow, etc. are registered
       - Add paginationControls: "/partials/paginationControls.hbs"

    6. Add a dashboard integration test that verifies pagination controls appear:
       - Create 25 builds for a service
       - GET /dashboard/my-service (page 1)
       - Assert response contains "Page 1 of 2"
       - Assert response contains "Next" link
       - Assert Previous is rendered as disabled span (cursor-not-allowed)

  </action>
